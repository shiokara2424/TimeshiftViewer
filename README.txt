Timeshift Viewer
================
キャプチャボードの映像と音声を表示しながら、直近の映像をメモリに保持して巻き戻し再生できるソフトです。
古い分は自動で破棄します（既定は10分）。

■ 使い方
1. TimeshiftViewer.exe をダブルクリック
   （初回のみ ffmpeg と mpv を自動でダウンロードします。約200MB。同じフォルダの tools に保存されます）
2. 映像デバイスにキャプチャボードを選び、音声は
   「キャプチャボードの音声（映像デバイスから取得）」のまま「開始」
3. プレーヤーのウィンドウを閉じる（または Q）と設定画面に戻ります

※ 初回起動時に「Windows によって PC が保護されました」と出た場合は、
   「詳細情報」→「実行」を押してください（署名のない自作アプリのため表示されます）。
※ .NET Framework 4.8（Windows 10/11 に標準搭載）で動作します。

■ 操作
  Space / 右クリック ... 一時停止・再開（ライブ中に押すとその瞬間で止まります）
  ← →               ... 5秒戻る / 進む
  Shift + ← →       ... 10秒戻る / 進む
  J                  ... 60秒戻る
  Home / End         ... 最古の位置へ / ライブへ戻る
  , .                ... コマ送り（前 / 次）
  ↑ ↓ / ホイール     ... 音量
  M                  ... ミュート
  F / ダブルクリック ... 全画面
  画面下のボタン ... « 10s / « 5s / 一時停止 / 5s » / 10s » / LIVE
                   （連打すると押した分だけ積み上げて移動します）
  画面下のバーをクリック ... その位置へ移動

■ うまくいかないとき
  ・音声が入らない → 設定画面の「音声」で別の項目を試してください
  ・開始できない → 解像度・フレームレートを「入力のまま」に
  ・カクつく → エンコーダを変える、画質を下げる
  ・取り込みのログは ffmpeg-log.txt に保存されます
