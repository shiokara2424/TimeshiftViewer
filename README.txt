Timeshift Viewer
================
キャプチャボードの映像と音声を表示しながら、直近の映像をメモリに保持して巻き戻し再生できるソフトです。
古い分は自動で破棄します（既定は10分）。

■ 使い方
1. TimeshiftViewer.exe をダブルクリック
   （初回のみ ffmpeg と mpv を自動でダウンロードします。約200MB。同じフォルダの tools に保存されます）
2. 映像デバイスにキャプチャボードを選び、音声は
   「キャプチャボードの音声（映像デバイスから取得）」のまま「開始」
3. プレーヤーのウィンドウを閉じる（または Q）と設定画面に戻ります

※ 初回起動時に「Windows によって PC が保護されました」と出た場合は、
   「詳細情報」→「実行」を押してください（署名のない自作アプリのため表示されます）。
※ .NET Framework 4.8（Windows 10/11 に標準搭載）で動作します。

■ 操作
  Space / 右クリック ... 一時停止・再開（ライブ中に押すとその瞬間で止まります）
  ← →               ... 5秒戻る / 進む
  Shift + ← →       ... 10秒戻る / 進む
  J                  ... 60秒戻る
  Home / End         ... 最古の位置へ / ライブへ戻る
  , .                ... コマ送り（前 / 次）
  ↑ ↓ / ホイール     ... 音量
  M                  ... ミュート
  F / ダブルクリック ... 全画面
  画面下のボタン ... « 10s / « 5s / 一時停止 / 5s » / 10s » / LIVE
                   （連打すると押した分だけ積み上げて移動します）
  画面下のバーをクリック ... その位置へ移動
  Tab                ... 画面下の操作パネルを隠す / 出す
  S                  ... スクリーンショット（screenshots フォルダに保存）

■ ペン
  P または画面下の ✎ ... ペンを開始（左ドラッグで書く）
  画面中央のパレット ... 色（6色）の切り替え / 戻す / 全消し / 終了
  1〜6 / Ctrl+Z / C  ... 色 / 1つ戻す / 全消し（キーでも操作できます）
  設定画面の「ライブに戻ったらペンの書き込みを消す」で、LIVE に戻ったときに自動で消えます

■ ぷよぷよeスポーツの見直し
  ・対戦の開始（ゴー！）と終了（勝利数が増えたとき）を自動で検知し、
    シークバーに試合の区間と「第N戦 名前 勝利数 名前 / Set / 結果」を表示します
    （設定画面のチェックで切り替え）
  ・T または画面下の「シミュ」でシミュレーターをウィンドウ全体に重ねて開きます（再生は一時停止し、
    閉じると開く前の状態に戻ります）。LIVE ボタンや End でライブに戻ると閉じます。開いたときに、今の画面の 1P・2P 両方の盤面と、その試合のツモ・
    それぞれ何手目かを読み込みます。操作するのは 1P（Tab・ボタン・盤面のクリックで 2P に切り替え）。
    「画面から読み込む」で読み直し
  ・シミュレーターの操作: ← → 移動 / Z X 回転 / ↓ Space 置く / Ctrl+Z 戻す / Ctrl+Y やり直し
    「盤面を編集」でぷよを置いて「連鎖させる」、「ツモの設定」で開幕からのツモを入力してパターンを特定
    ツモが1つに絞れないときは候補から無作為に選んだツモで動きます（表示に「仮」と出ます）
  ・シミュレーターを操作するときは一度シミュレーターをクリックし、映像に戻るときは映像をクリックしてください
  ※ OBS のウィンドウキャプチャは、このバージョンからプレーヤーが TimeshiftViewer.exe のウィンドウになったため、
     一度「Timeshift Viewer」ウィンドウを選び直してください（キャプチャ方法は「Windows 10 (1903以降)」を推奨）

■ うまくいかないとき
  ・音声が入らない → 設定画面の「音声」で別の項目を試してください
  ・開始できない → 解像度・フレームレートを「入力のまま」に
  ・カクつく → エンコーダを変える、画質を下げる
  ・取り込みのログは ffmpeg-log.txt に保存されます
